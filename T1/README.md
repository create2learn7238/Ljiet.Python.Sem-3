## 📋 Course Overview

This repository contains comprehensive Python programming materials for Semester 3 at LJ Institute of Engineering & Technology. It covers fundamental to intermediate Python concepts with practical Jupyter notebooks, example programs, and theoretical PDFs.

## 📚 Course Content

### 🧩 Unit 1: Python Fundamentals
- **Identifiers & Naming Rules** - Rules for naming variables, functions, and classes
- **Data Types** - int, float, complex, str, list, tuple, range, dict, set, frozenset, bool
- **Number Systems** - Binary, Octal, Hexadecimal and base conversions
- **Typecasting** - Converting between different data types
- **Basic Operations** - Arithmetic, comparison, logical, membership operators
- **Operator Precedence** - Order of operations in Python

### 🔀 Unit 2: Conditional Execution & Iteration
- **Conditional Statements** - if, if-else, if-elif-else, nested if
- **Loops** - for loop, while loop, nested loops
- **Loop Control** - break, continue statements
- **Pattern Printing** - Various star and number patterns
- **Mathematical Problems** - Armstrong numbers, palindrome, prime numbers, happy numbers
- **Real-world Applications** - Electricity bill calculator, wage calculator, triangle classifier

### 🔧 Unit 3: Functions & Scoping
- **Function Types** - Built-in vs User-defined functions
- **Function Categories**:
  - No parameter & no return type
  - With parameter & no return type
  - With parameter & with return type
  - No parameter & with return type
- **Arguments Types** - Positional, keyword, default, variable-length (*args, **kwargs)
- **Return Statement** - Single and multiple return values
- **DocStrings** - Function documentation
- **Nested Functions** - Functions inside functions
- **Scope** - Local vs Global variables
- **Mathematical Functions** - Using math module
