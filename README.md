## 📋 Course Overview

This comprehensive course introduces fundamental concepts of computer science through Python programming. With a strong emphasis on hands-on learning (6 practical hours weekly), students will progress from basic syntax to object-oriented programming and data visualization.

---

## 📚 Syllabus Breakdown

### Unit 1: Introduction to Python & Jupyter Notebooks (5%)
- Basic Data Types: integers, Booleans, floats, strings
- Variables, type casting, input/output operations
- Arithmetic, Logical, Membership, Assignment, Comparison Operators
- Jupyter Notebook environment setup and navigation

### Unit 2: Conditional Execution & Iterations (15%)
- Control Statements: if, if-else, if-elif-else, nested if
- Loops: for with range, while with else
- Loop control: break, continue, pass

### Unit 3: Functions, Scoping & Abstraction (5%)
- Function declaration, definition, and invocation
- Argument types: keyword, default, positional, variable-length
- Local vs global variables, nested functions

### Unit 4: Immutable Data Structures (10%)
- **Strings:** slicing, concatenation, various methods
- **Tuples:** creation, access, comprehension, generators
- Built-in functions: sorted, reversed, min, max

### Unit 5: Mutable Data Structures (15%)
- **Lists:** methods, comprehension, mutability
- **Dictionaries:** creation, access, comprehension
- **Sets:** operations, frozenset, set comprehension
- Lambda functions with map, reduce, filter

### Unit 6: Working with Files (10%)
- Text file operations (read, write, append modes)
- File methods: read(), readline(), readlines()
- seek() and tell() functions

### Unit 7: Modules & Directories (5%)
- Git basics
- Modules vs Packages, import variations
- OS Module: getcwd(), chdir(), mkdir(), listdir()
- Datetime module

### Unit 8: Introduction to OOP & Exception Handling (8%)
- Classes, objects, attributes, methods
- Constructors, destructors
- Exception handling: try, except, finally
- Custom exceptions

### Unit 9: Advanced OOP Concepts & NumPy (17%)
- Polymorphism (overloading, overriding)
- Inheritance (single, multi-level)
- Method Resolution Order (MRO), Abstract classes
- NumPy arrays: 1D, 2D, 3D creation and manipulation

### Unit 10: Visualization & Streamlit UI (10%)
- Matplotlib: line plots, scatter plots, bar charts
- Histograms, pie charts, area plots
- Streamlit: UI widgets, input handling, chart integration
